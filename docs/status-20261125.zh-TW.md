# 2026-11-25 功能進度查驗

本文件支援 `README.md` 的逐項進度表。查驗範圍為 `records/items/*`、實機開機日誌、主機測試與建置 manifest；**本次撰寫整理文件本身沒有新增實機測試，也沒有操作手機**。

原始紀錄（`boot.log`、`report.json`、`mtd` 紀錄、量測檔）保存在開發工作區，不收進本倉庫。以下 `R/` 代表開發工作區的執行紀錄目錄索引，並非本倉庫既有檔案；程式、補丁、研發紀錄與說明文件則已收錄，見[來源與目錄說明](source-layout.zh-TW.md)與[紀錄庫索引](../records/README.zh-TW.md)。本文只整理必要數值，不收錄裝置序號、網路名稱、MAC、IP、本機使用者路徑、電郵、憑證、手機備份或專有系統二進位。

「已驗證」限於記載的版本與情境（特別標註本機建置為 `local-wsl (not a CI artifact)`）；「尚未驗收」或「暫緩」表示目前查閱範圍內沒有通過紀錄或依決策排除，不表示已證明硬體不可能支援。使用者的實際操作確認與程式自動紀錄分開記載。

2026-11-18 以前的基礎查驗項目（`E1`–`E16`）見 [2026-11-18 功能進度查驗](status-20261118.zh-TW.md) 與 [CPU 與 GPU 最終狀態](cpu-gpu-final-20261118.zh-TW.md)；本頁接續整理 2026-11-18 至 2026-11-25（`B-015` → `B-021`）的新增與定案項目。

### E28：目前暫緩與尚未驗收項目的界線

截至 2026-11-25 `B-021`，以下項目明確列為暫緩排除或尚未完成實機驗收：
